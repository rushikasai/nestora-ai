# Nestora AI 🏡

### AI-Powered Home Planning Assistant

Nestora AI is an AI-powered home planning assistant designed to help families organise their home requirements and explore practical planning ideas based on their plot size, family needs, and budget.

## 🌟 Features

- **Smart Home Planning:** Explore home-planning ideas based on family requirements.
- **Space Utilisation:** Get suggestions for making better use of available space.
- **Budget Guidance:** Understand possible construction costs and budget considerations.
- **Family-Based Suggestions:** Organise room and space requirements based on family size.
- **Conversational Assistance:** Ask questions and refine your home-planning requirements through chat.

## 🎯 Problem Statement

Planning a home can be challenging for families who need to balance available space, budget, comfort, and everyday needs.

Nestora AI aims to make the initial planning process easier by providing accessible, AI-powered guidance in one place.

## ⚙️ How It Works

1. The user describes their plot dimensions, budget, and family requirements.
2. The assistant understands the user's planning needs.
3. It provides relevant home-planning suggestions and budget guidance.
4. The user can ask follow-up questions to refine the plan.

## 🛠️ Technology Stack

- Python
- Fetch.ai uAgents, if used in the implementation
- Agentverse, for hosting and discovering the agent
- ASI:One / ASI1, if configured in the project

## 🚀 Getting Started

1. Clone or download this repository.
2. Install the dependencies listed in `requirements.txt`.
3. Configure the required environment variables using `.env.example` as a reference.
4. Follow the instructions for the actual agent entry-point file.
5. Run and test the agent according to its implementation.

## ⚠️ Important Note

Nestora AI provides preliminary planning ideas, not certified architectural or structural designs. Construction plans, structural safety, local building regulations, and final cost estimates should be reviewed by qualified professionals.
